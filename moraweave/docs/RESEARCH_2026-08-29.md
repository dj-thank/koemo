## 1. Directly implemented

### Calibrated evidence fusion

The original per-candidate min-max transform was replaced with:

- persisted scalar calibration profiles when a held-out set exists;
- robust median/MAD score transforms as an explicit fallback;
- beam rank, average log probability and next-hypothesis margin features;
- posterior probabilities, entropy, Jensen-Shannon stream disagreement, evidence coverage and selective risk;
- an abstention state that marks the observation `provisional` instead of presenting uncertainty as fact.

Implemented in:

```text
src/moraweave/calibration.py
src/moraweave/gates.py
src/moraweave/contracts/frontier.py
src/moraweave/calibrate_cli.py
```

### Dual surface/mora shadow lattice

When every candidate has a reading or mora sequence, the lattice aligns mora rather than surface characters. Therefore `今日` and `きょう` can share one phonological spine while a real phonological difference remains a contradiction island.

Contradiction islands are classified for numbers, dates/times, currency, particles, Latin technical terms, kanji/proper nouns and special mora. Critical islands receive more evidence-acquisition budget.

Implemented in:

```text
src/moraweave/shadow_lattice.py
src/moraweave/acquisition.py
src/moraweave/selective.py
```

### Query-selected evidence acquisition

Additional inference is selected by expected information gain divided by estimated cost. Available actions are:

```text
Whisper local re-listening
Qwen3-ASR second ear
Qwen3 Forced Aligner
local teacher check
```

This is a MoraWeave mechanism. It is inspired by query-selected access patterns in efficient long-context models, but it is not Qwen3.8's QSA kernel.

### Runtime evidence cache v2

The cache key binds:

```text
source audio SHA-256
exact time span
adapter and model
language
beam and hypothesis count
prompt, hotword and context digests
calibration digest
schema version
```

The cache stores no waveform. It preserves candidate rank, score, source, reading, mora evidence and teacher abstention. Unknown cache schema versions fail closed.

### Official Qwen3-ASR integration contract

The adapter now:

- maps `ja`, `jpn`, `日本語` to the official `Japanese` value;
- supports requested audio spans instead of silently decoding the whole file;
- records the installed `qwen-asr` version;
- can request timestamps;
- exposes a separate Qwen3 Forced Aligner adapter;
- documents that the official wrapper normally returns one transcript per input, not a true decoder N-best list.

### Delayed local Qwen3.8 teacher

Qwen3.8 is an optional local teacher behind an OpenAI-compatible loopback endpoint. It is invoked only after acoustic fusion finds an ambiguous region. It may return probabilities for existing candidate IDs or abstain; it cannot author `observedTranscript` text.

Network controls:

- loopback HTTP only;
- no URL credentials/query/fragment;
- environment proxies disabled;
- redirects blocked;
- structured candidate-ID response required;
- thinking content is not persisted by default.

## 2. Architecture translations, not reproductions

| Qwen3.8 design idea | MoraWeave translation | Claim boundary |
|---|---|---|
| Query-selected state access | Query-selected acoustic/evidence memory | Scheduling analogy only; no QSA kernel copied |
| Gated branch composition | Acoustic, mora, lexical and preservation evidence gates | Evidence-level fusion, not transformer residual architecture |
| Lexical/n-gram augmentation | Rights-gated hashed n-gram memory | No Qwen embedding table or weights used |
| Efficient long-context inference | Long-audio windows, locked consensus, localized re-listening and cache | Audio orchestration translation |
| Delayed high-capacity reasoning | Ambiguity-only local Qwen teacher | Teacher never replaces acoustic evidence |

## 3. Unvalidated hypotheses

The following are research hypotheses and must not be described as measured improvements until benchmarked:

1. Mora-shadow islands reduce unnecessary re-decoding while preserving or improving kana-CER and MLER.
2. Expected-information-gain scheduling yields lower RTF at equal CER than always running two ASR models.
3. The grammar-honeytrap penalty improves learner-error preservation without increasing ordinary Japanese CER.
4. Held-out posterior calibration lowers ECE and AURC across microphones, speakers and domains.
5. Hashed JMdict/public-corpus lexical memory improves proper nouns without storing reconstructable source text.
6. A preservation auxiliary head can distinguish filler, repair and learner error from noise.
7. Qwen3.8 teacher abstention is more reliable than unrestricted free rewriting for observed-speech recovery.

## 4. Required ablations

```text
+ selective re-listening

```

```text

filler/repair preservation
unsupported correction rate
ECE, Brier, NLL, AURC
coverage at fixed risk
RTF, peak VRAM, cache hit rate
information gain per added inference millisecond
```

## 5. Evidence standard

A repository test proves a contract or deterministic algorithm, not real recognition quality. Real-model and corpus claims require:

- exact model and package versions;
- immutable evaluation manifests and audio hashes;
- speaker-disjoint splits;
- confidence intervals or paired bootstrap comparisons;
- public failure examples where licences permit;
- explicit disclosure of unavailable or rights-restricted data.
